# GRE General Test 최신 정보 (2026년 8월 기준)

> 2023-09-22부터 시행 중인 **단축형 GRE**가 현행 포맷. 조사일: 2026-08-13. 출처: `../05-resources/references.md` #시험정보

## 시험 구조 (총 약 1시간 58분, 휴식 없음)

| 순서 | 섹션 | 문항/과제 | 시간 |
|---|---|---|---|
| 1 | Analytical Writing (AWA) | Issue 에세이 1개 (Argument 폐지됨) | 30분 |
| 2~5 | Verbal 섹션 1 | 12문항 | 18분 |
| | Verbal 섹션 2 | 15문항 | 23분 |
| | Quant 섹션 1 | 12문항 | 21분 |
| | Quant 섹션 2 | 15문항 | 26분 |

- AWA가 항상 첫 번째, 이후 Verbal/Quant 순서는 무작위
- **실험(unscored) 섹션 없음** — 모든 문항이 점수에 반영
- **섹션 적응형**: 섹션 1 성적에 따라 섹션 2의 난이도(=도달 가능한 점수 상한)가 결정됨 → **섹션 1이 결정적으로 중요**
- 섹션 내에서 문제 건너뛰기·돌아가기·답 수정 가능 (Mark & Review 기능)
- 오답 감점 없음 → **절대 빈칸으로 두지 말 것**

## 점수 체계

- Verbal / Quant: 각 130–170 (1점 단위)
- AWA: 0–6 (0.5점 단위)
- 성적 발표: 응시 후 8–10일
- ScoreSelect: 원하는 회차 점수만 골라서 학교에 전송 가능 → **못 봐도 기록이 강제 전송되지 않음**

## 응시 정보

- 응시료: **$220** (대부분 국가 공통)
- 재응시 규정: 21일 간격, 12개월 내 5회까지
- 한국: 테스트센터 응시(월 3회 한정) 또는 **GRE at Home**(24/7 가능, 웹캠 감독) — 한 달 속성 일정엔 at Home이 날짜 유연성 면에서 유리. 단, 조용한 독립 공간·요건 충족 필요
- 접수: ETS 계정 → https://www.ets.org/gre

## 문항 유형 요약

**Verbal (섹션당)**: Text Completion(빈칸 1~3개), Sentence Equivalence(동의어 2개 고르기), Reading Comprehension(단문~장문 지문)
**Quant**: Quantitative Comparison(A/B 크기 비교), Multiple Choice(단일/복수 정답), Numeric Entry(직접 입력), Data Interpretation(자료 해석 세트) — 화면 계산기 제공

## 전략적 시사점 (한 달 플랜에 반영됨)

1. 섹션 적응형 → 섹션 1(12문항)에서 최대한 정확도 확보하는 훈련 필요
2. AWA가 맨 처음 → 모의고사 때도 에세이부터 쓰는 습관
3. 2시간 시험 → 체력 부담이 과거보다 적어 단기 속성에 유리
4. Mark & Review → "막히면 표시하고 넘어가기" 루틴을 처음부터 체화
