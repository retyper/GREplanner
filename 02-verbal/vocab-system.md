# 어휘 시스템 (4주 완성)

## 세팅 (Day 1에 완료)

1. **Anki 설치** (무료, https://apps.ankiweb.net) — PC + 폰 동기화
2. 공유덱 다운로드 (AnkiWeb에서 검색, 무료):
   - "GregMat Vocab" (Group 1–34, 약 900단어, 고빈도 순 정렬) ← **메인**
   - 보조: "Magoosh GRE 1000" (GregMat 덱 소진 후)
3. Anki 설정: 신규 카드 **40/일** (트랙 A·B 공통 — 2026-08-21 재조정), 복습 무제한
4. 대안(앱 설치 싫으면): Magoosh Vocabulary Flashcards 웹/앱 — 단, Anki의 간격반복이 한 달 속성엔 더 효율적

## 일일 루틴 (총 40–50분, 저녁 세션 + 자투리 시간)

- 아침: 어제 신규 단어 빠른 재확인 (5분)
- 저녁: Anki 신규 40개 + 밀린 복습 전부 (30–40분)
- 자투리(폰): 복습 카드 소진
- **문제에서 만난 모르는 단어는 즉시 Anki에 직접 추가** — 실전 출처 단어가 최우선 암기 대상

## 암기 방법 (단순 뜻 암기 금지)

각 단어를 3요소로: ① 뜻 ② **긍정/부정/중립 뉘앙스** ③ 예문 하나
- GRE TC/SE는 뉘앙스 방향만 알아도 풀리는 문제가 많음
- 어원(라틴 어근) 묶음 암기: e.g. `loqu/loc`(말하다) → loquacious, eloquent, circumlocution
- `/vocab-quiz` 로 Claude와 문맥 퀴즈 (단어→뜻이 아니라 **문장 빈칸에 맞는 단어 고르기** 형식)
