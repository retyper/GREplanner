# Quant 공부법 (목표: 트랙 A 168+ / 트랙 B 163+)

## 핵심 원칙

GRE Quant는 고교 수준 수학이지만 **함정 설계 + 시간 압박** 시험. 개념 복구(Week 1) → 유형 전략(Week 2) → 볼륨/속도(Week 3) → 실전(Week 4) 순서로 간다. 문제당 평균 1분 45초.

## 무료 자료 (우선순위 순)

1. **ETS Math Review PDF** (무료, 공식) — 출제 범위의 유일한 공식 정의. Week 1 교재
2. **Khan Academy** — ETS가 공식으로 토픽별 매핑을 제공. 개념 구멍 메울 때 해당 영상만 골라 시청
3. **ETS Math Conventions PDF** — 표기 규약 (정수 정의, 도형 비례 여부 등 함정 방지)
4. **PowerPrep 문제 + ETS 공식 무료 PDF 모의고사** — 실전 문제의 표준
5. GregMat YouTube 무료 Quant 전략 영상 / gre.myprepclub.com 무료 문제 은행(Big Book 포함)

## 토픽 체크리스트 (ETS Math Review 기준 4개 영역)

각 토픽을 학습하면 `[ ]`→`[x]`, 오답이 나오면 `⚠` 표시.

### Arithmetic
- [ ] 정수 성질 (약수/배수, 소수, 홀짝, 나머지)
- [ ] 분수·소수·비율·퍼센트 (변화율, 연속 퍼센트 함정)
- [ ] 지수·근호 규칙
- [ ] 절댓값, 수직선

### Algebra
- [ ] 일차/이차 방정식·부등식
- [ ] 함수, 지수함수 성질
- [ ] 좌표기하 (직선, 기울기, 거리, 원)
- [ ] 문장제 → 식 변환 (일/속도/농도/이자)

### Geometry
- [ ] 각·삼각형 (특수삼각형 3-4-5, 30-60-90, 45-45-90)
- [ ] 사각형·다각형·원 (내접/외접)
- [ ] 입체 (부피, 겉넓이, 대각선)
- [ ] ⚠ GRE 도형은 비례가 아님 (Math Conventions)

### Data Analysis ← **출제 비중 최대, 통계 트랙 필수 만점 영역**
- [ ] 평균·중앙값·최빈값·범위·표준편차 (개념적 비교 문제)
- [ ] 사분위수, boxplot, 정규분포 근사
- [ ] 경우의 수·순열조합·확률 (조건부, 여사건)
- [ ] 자료 해석 (그래프/표 세트 문제 — 시간 관리 핵심)

## 유형별 전략

**Quantitative Comparison (비중 ~40%)**: 계산 전에 "D(비교불가) 가능성"부터 의심. 숫자 대입은 {0, 1, -1, 1/2, 큰 수} 세트로. 양변에 같은 연산(음수 곱 주의)으로 단순화
**Multiple Choice 복수정답**: 정답 개수 힌트 없음 — 전 선택지 검증
**Numeric Entry**: 단위·반올림 지시 재확인
**Data Interpretation**: 그래프 축·단위 먼저 30초 스캔 후 문제 진입

## 일일 루틴 (오전 세션)

1. 개념 학습/복구 (Week 1–2) 또는 타이머 문제 세트 (Week 3–4)
2. **모든 오답 + 찍어서 맞은 문제 → 오답노트** (`../05-resources/error-log.md`)
3. 오답은 다음날 아침 다시 풀기 (해설 안 보고)

## 168+를 위한 추가 규칙 (트랙 A)

- 쉬운 문제 실수 = 최대의 적. 섹션 1에서 12/12 정확도 목표의 "느리게 풀어도 다 맞기" 훈련부터 시작해 점차 속도 상승
- 하루 2문제는 "hard 난이도"를 시간 무제한으로 풀고 풀이를 남에게 설명하듯 서술
- 마지막 5분 검산 루틴: Mark해둔 문제 → 계산 실수 스캔
