# /gre-daily

1. 오늘 날짜를 확인하고 해당하는 `04-schedule/weekN.md`의 그 날 계획을 읽는다 (8/21~8/24=week1, 8/25~8/31=week2, 9/1~9/7=week3, 9/8~9/13=week4).
2. `.learner` 파일로 학습자(A/B)를 확인하고 (없으면 한 번 묻고 생성), 트랙별 시간 배분을 반영해 오늘의 할 일을 3–5줄로 브리핑한다.
3. 개인 로그(`05-resources/log-{A|B}.md`)의 최근 약점을 확인해 "오늘의 집중 포인트" 1개를 제안한다.
4. 어제 체크박스 미완료 항목이 있으면 오늘 계획에 어떻게 흡수할지 제안한다.
5. 학습자가 원하면: 연습 문제 출제(현행 GRE 형식, `00-overview/gre-2026-info.md` 준수), 개념 설명, 타이머 세트 안내 등 세션을 이어간다.
6. 세션 종료 시("오늘 끝" 등) 완료 항목을 개인 로그의 "일일 완료 체크"에 한 줄 추가하고 오답을 기록한 뒤 `/gre-sync`를 제안한다. 스케줄 파일 체크박스는 건드리지 않는다.
