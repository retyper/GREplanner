# /gre-daily

1. 오늘 날짜를 확인하고 해당하는 `04-schedule/weekN.md`의 그 날 계획을 읽는다 (8/14~8/20=week1, 8/21~27=week2, 8/28~9/3=week3, 9/4~=week4).
2. 학습자가 A/B 중 누구인지 (또는 둘 다인지) 물어보고, 트랙별 시간 배분을 반영해 오늘의 할 일을 3–5줄로 브리핑한다.
3. `05-resources/error-log.md`의 최근 약점을 확인해 "오늘의 집중 포인트" 1개를 제안한다.
4. 어제 체크박스 미완료 항목이 있으면 오늘 계획에 어떻게 흡수할지 제안한다.
5. 학습자가 원하면: 연습 문제 출제(현행 GRE 형식, `00-overview/gre-2026-info.md` 준수), 개념 설명, 타이머 세트 안내 등 세션을 이어간다.
6. 세션 종료 시("오늘 끝" 등) 완료 항목을 스케줄 파일에 `[x]` 반영하고 오답을 error-log에 기록한다.
