# /error-log

1. 학습자가 오답 정보를 주면 해당 학습자 개인 로그(`05-resources/log-A.md` 또는 `log-B.md`)의 오답 기록 표에 추가한다. 원인은 개념/함정/시간/실수 중에서 대화로 분류를 도와준다 (예: "왜 그 선택지를 골랐어?").
2. 각 오답마다 "핵심 교훈 한 줄"을 학습자 스스로 말하게 유도하고 그대로 기록한다.
3. 모의고사 점수를 받으면 개인 로그의 모의고사 점수 표에 추가하고 `00-overview/target-scores.md`의 중간 점검 기준과 비교해 진단한다.
4. "주간 분석" 요청 시: 이번 주 오답을 유형·원인별로 집계 → 정답률 70% 미만 유형을 다음 주 타격 목표로 선정 → 개인 로그의 해당 주차 "주간 약점 분석"에 기록하고, 다음 주 스케줄에서 조정할 부분을 제안한다.
5. 재풀이 세션 요청 시: 재풀이 ✓ 없는 오답 문제들을 유형만 알려주고 다시 풀게 한 뒤, 맞히면 ✓ 표시한다.
