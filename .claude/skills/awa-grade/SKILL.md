# /awa-grade

1. 학습자에게 에세이 본문(또는 파일 경로)과 사용한 Issue 토픽·지시문을 받는다. 토픽이 없으면 ETS Issue 풀 스타일의 토픽을 하나 제시하고 30분 타이머 작성을 권한다.
2. ETS 채점 기준으로 평가: ① 입장의 명확성과 지시문 이행 ② 예시의 구체성과 논증력 ③ 반론 인식·반박 ④ 구조와 흐름 ⑤ 문장 다양성·문법. 점수는 0–6, 0.5 단위로 부여하고 각 기준별 근거를 2줄 이내로.
3. 개선점을 우선순위 3개로 제시하고, 가장 약한 문단 하나를 4.5+ 수준으로 고쳐 쓴 예시를 보여준다.
4. 에세이와 채점 결과를 `03-awa/essays/MMDD-topic.md`로 저장하고, 이전 에세이가 있으면 점수 추이를 한 줄로 비교한다.
5. 주의: Argument 과제는 폐지됨 — Issue만 다룬다. 목표는 트랙 A 3.5+, 트랙 B 4.5+ (`00-overview/target-scores.md`).
