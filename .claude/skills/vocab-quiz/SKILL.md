# /vocab-quiz

1. `02-verbal/vocab-system.md`의 진도 기록에서 현재 학습 범위(GregMat Group 번호)를 확인한다. 기록이 없으면 학습자에게 현재 진도를 묻고 기록한다.
2. 인자로 문항 수가 오면 그만큼, 없으면 10문항 출제한다. 형식은 실전형만 사용:
   - Text Completion 스타일: 문장 빈칸에 맞는 단어 고르기 (5지선다)
   - Sentence Equivalence 스타일: 6개 중 같은 의미가 되는 2개 고르기
   - 최근 배운 단어 70% + 이전 누적 복습 30% 비율
3. 한 문항씩 내고 답을 받은 뒤 정오답 판정 + 오답 시 뉘앙스(긍/부/중립)와 어원 힌트로 짧게 해설한다.
4. 종료 시 정답률 요약, 틀린 단어 목록을 제시하고 "Anki에 다시 추가할 것"을 안내한다. 주간 체크(50문항)였다면 결과를 `02-verbal/vocab-system.md` 진도 기록에 남긴다.
