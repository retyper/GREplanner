# 토큰 절약 규칙 (Claude 비용 관리)

> 배경: 학습자 B가 이 레포에서 세션 하나에 $70을 태움 (2026-08-21 보고). 원인은 대부분 **같은 파일을 반복해서 통째로 읽고, 통째로 다시 쓰는 것**이다. 이 파일은 Claude와 학습자 양쪽이 지키는 규칙이다.

## 비용이 새는 지점 (비싼 순서)

| 순위 | 행동 | 대략 비용 | 대체 |
|---|---|---|---|
| 1 | 서브에이전트/워크플로 fan-out (`Agent`, `Workflow`) | 세션당 $10~50 | **GRE 작업에는 절대 쓰지 않는다.** 이 레포는 md 몇 개짜리 단일 작업 |
| 2 | 웹 검색 + 페이지 fetch 반복 | 회당 $0.5~3 | `references.md`에 이미 있는지 먼저 확인. 없을 때만 1회 |
| 3 | 파일 전체 재출력 (수정본 통째 rewrite) | 파일당 $0.2~1 | 바뀐 줄만 교체 (Edit/sed). 표 한 줄 추가에 파일 전체를 다시 쓰지 않는다 |
| 4 | 긴 대화를 끊지 않고 계속 이어가기 | 턴마다 누적 | 주제 바뀌면 `/clear`. 컨텍스트는 매 턴 전부 재과금된다 |
| 5 | 문제 50문항 한 번에 생성 | 회당 $0.3~1 | 10문항씩. 어차피 한 번에 50개 못 푼다 |

## Claude가 지킬 것

1. **읽기는 부분만**: `sed -n '20,40p' file.md`, `grep -n`. `cat` 전체는 파일이 40줄 미만일 때만.
2. **쓰기는 diff만**: 표에 한 줄 추가 = 그 줄만 추가. 파일 전체 heredoc rewrite는 구조 자체가 바뀔 때만.
3. **에이전트·워크플로 금지**: 이 레포 작업에 `Agent`/`Workflow` 툴 사용 안 함.
4. **웹 검색은 최후 수단**: 시험 형식·점수 정보는 `00-overview/`와 `05-resources/references.md`가 진실 소스. 여기 없고 학습에 꼭 필요할 때만 1회 검색.
5. **문제 출제는 10개 단위**, 해설은 학습자가 답을 제출한 뒤에만. 미리 전부 출력하지 않는다.
6. **긴 인용 금지**: 스케줄·가이드를 다시 읽어줄 때 원문 복사 대신 "8/22: SE 20문항 + RC 2지문" 처럼 압축.
7. **AWA 채점**: 원문을 통째로 재출력하지 않는다. 문제 문장만 인용해서 지적. (에세이 파일에는 원문 1회만 저장)
8. **요약 금지**: 세션 끝에 "오늘 한 일" 장문 리포트를 자동 생성하지 않는다. 요청받을 때만.

## 학습자가 지킬 것

- **세션 단위를 짧게**: 오전 Quant 끝나고 `/clear`, 오후 Verbal 새 세션. 하루 종일 한 세션 유지가 가장 비싸다.
- **Claude에 시킬 것 / 안 시킬 것**
  - 시킬 것: 오답 원인 분석, 어휘 문맥 퀴즈, AWA 채점, 개념 설명, 계획 조정
  - 시키지 말 것: 대량 문제 생성(무료 문제은행이 훨씬 쌈 — `references.md` #무료자료), 이미 아는 내용 재설명, 파일 정리·리팩터링
- **모델**: 채점·개념설명은 Sonnet으로 충분. `/model` 로 전환. Opus는 계획 재조정·약점 분석처럼 판단이 필요한 작업에만.
- **한 번에 하나**: "이것도 저것도" 대신 질문 하나 → 답 → 종료.
