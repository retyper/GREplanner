# 오답노트 규칙 (공용 인덱스)

> **개인 기록은 여기 쓰지 않는다.** 충돌 방지를 위해 학습자별 파일로 분리됨:
> - 학습자 A → [`log-A.md`](log-A.md)
> - 학습자 B → [`log-B.md`](log-B.md)
>
> 이 파일은 규칙만 담으며 거의 수정되지 않는다. (수정 = 두 사람 합의 사항일 때만)

## 무엇을 기록하나
**틀린 문제 + 찍어서 맞은 문제 + 2분 초과 문제** 전부.

## 원인 분류
- `개념` — 몰라서 (→ 해당 단원 재학습)
- `함정` — 문제 설계에 당함 (→ 함정 패턴을 한 줄 규칙으로)
- `시간` — 쫓겨서 (→ 포기 타이밍 규칙)
- `실수` — 계산·독해 실수 (→ 체크 습관)

## 기록 형식
각 오답마다 **"핵심 교훈 한 줄"을 학습자 본인 말로** 남긴다. 해설 복사 금지 — 재풀이 때 이 한 줄만 읽는다.

## 주간 분석 (매주 마감일)
유형·원인별 집계 → 정답률 70% 미만 유형 = 다음 주 타격 목표 → 개인 로그의 "주간 약점 분석"에 기록하고 스케줄 조정.
