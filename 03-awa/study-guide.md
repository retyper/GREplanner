# AWA 공부법 — Issue 에세이 1개, 30분 (목표: 트랙 A 3.5+ / 트랙 B 4.5+)

## 현행 규정

- **"Analyze an Issue" 1개만** 출제 (Argument 과제는 2023년 폐지 — 옛 자료의 Argument 파트는 건너뛸 것)
- 시험의 맨 처음 30분
- **전체 기출 토픽 풀이 ETS 사이트에 공개**되어 있음 — 실제 시험 문제는 이 풀에서 나옴 (references.md #AWA)
- 채점: 사람 + AI(e-rater) 병행, 0–6점 0.5 단위

## 4.0+ 에세이의 조건 (ETS 채점 기준 요약)

1. 명확한 입장 + 지시문(instruction) 요구사항 이행 ← 지시문 6종 패턴 숙지 필수
2. 구체적 예시로 뒷받침된 논리 전개 (역사/과학/사회/개인 경험 모두 허용)
3. 반론 인식 및 반박 (4.5+ 갈림길)
4. 조직적 구조, 다양한 문장 구조, 치명적이지 않은 수준의 문법

## 30분 템플릿

| 시간 | 작업 |
|---|---|
| 0–4분 | 지시문 확인 → 입장 결정 → 본론 포인트 2–3개 + 예시 메모 |
| 4–7분 | 서론: 이슈 재진술 + 명확한 thesis (+양보 한 줄) |
| 7–22분 | 본론 2–3문단: 주장→예시→분석. 문단당 5분 |
| 22–26분 | 반론 문단: "One might argue... however..." |
| 26–30분 | 결론 2–3문장 + 오탈자 스캔 |

분량 가이드: 500–600단어 (통계적으로 분량과 점수 상관 높음. 단, 반복·수사 부풀리기는 감점)

## 연습 스케줄

- Week 1: ETS 채점 기준 + 6점/4점 샘플 에세이 정독 (무료 공개), 템플릿 암기
- Week 2: 주 2회 — 시간 무제한으로 구조 연습 → `/awa-grade` 채점
- Week 3: 주 3회 — 30분 타이머 실전 → `/awa-grade` 채점 + 이전 에세이 대비 개선점 추적
- Week 4: 모의고사에 포함해서 (에세이부터 쓰고 Verbal/Quant 진입하는 실전 체력 훈련)
- 작성한 에세이는 `essays/` 폴더에 `MMDD-topic.md`로 저장

## 예시 은행 만들기 (트랙 B 특히)

자기 분야에서 재사용 가능한 예시 8–10개를 미리 문장으로 준비:
- 과학/기술: CRISPR 논쟁, AI 규제, 재현성 위기, 기후 모델링
- 사회/정치: 민주주의와 기술관료제, 보통선거 확대, 검열 논쟁, 복지 정책 실험
- 역사/인물: 갈릴레오, 산업혁명, 여성 참정권 운동
이 예시들은 거의 모든 Issue 토픽(교육/기술/사회/리더십/연구)에 변형 적용 가능.
